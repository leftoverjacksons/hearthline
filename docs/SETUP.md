# Setup: connecting a local Unity project to this repository

The repository was started without a Unity Editor. It contains the simulation, content, tests and a few
Unity scripts, but **no Unity project files** (`ProjectSettings/`, `Packages/`) and **no `.meta` files**.
Unity creates those; they then need to be committed. Nothing under `Assets/Hearthline/Bridge` or
`Assets/Hearthline/Game` has been compiled by Unity yet.

## First time

1. Install Git LFS once: `git lfs install`. Clone the repository.
2. In Unity Hub, create a new **Unity 6 (LTS)** project from the **Universal 3D (URP)** template in a
   temporary folder. Close the Editor.
3. Copy `ProjectSettings/` and `Packages/` from the temporary project into the clone, and merge the
   template's `Assets/` contents into the clone's `Assets/`.
4. Open the clone in Unity Hub (Add project from disk).
5. Package Manager → `+` → Install package by name: `com.unity.nuget.newtonsoft-json`. Also make sure
   **Test Framework** is installed.
6. Wait for compilation. Expected: no errors in `Hearthline.Sim`, `Hearthline.Bridge`, `Hearthline.Game`,
   `Hearthline.Tests.EditMode`. If `Hearthline.Sim` cannot find `Newtonsoft.Json.dll` or
   `YamlDotNet.dll`, check step 5 and that `Assets/Plugins/YamlDotNet/YamlDotNet.dll` imported.
7. Window → General → Test Runner → EditMode → Run All. The result should match `tools/test.sh`.
8. Commit everything Unity generated: `ProjectSettings/`, `Packages/`, and every new `.meta` file.

## Trying the M0 gate

`Assets/Scenes/M0_Greybox.unity` is set up for this: rolling greybox ground, **SimHost**, **CheatPanel**,
and the Starter Assets third-person mannequin and follow camera (ADR 0010), with **CharacterMarksView**
and a mark anchor on the bone for each body region. WASD moves, the mouse looks, Space jumps, Shift
runs; F1 toggles the cheat panel, which frees the mouse while it is open (it starts open).

Starter Assets comes from the Asset Store, so a fresh clone needs it: add "Starter Assets – Third
Person" to your Unity account, then Package Manager → My Assets → Download → Import. Move the imported
`Assets/Starter Assets` folder to `Assets/ThirdParty/StarterAssets` in the Project window.

The scene is generated by
`Assets/Hearthline/Editor/GreyboxSceneBuilder.cs`; change the builder and rebuild rather than editing the
scene by hand: menu **Hearthline → Rebuild M0 greybox scene**, or
`unity command script eval --code "return Hearthline.EditorTools.GreyboxSceneBuilder.Build();"`.

By hand: open the scene and press Play. In the cheat panel (F1), add `scar_claw` to Face, Save, start a
New game, then Load. The marker should be back on the face.

Automatically: `MarkPersistenceSmokeTest` (PlayMode) does the same steps against a throwaway save file:
`unity command test run --mode playmode --async-tests`, then `unity command test status --detail failures`.

Hits through the body: the cheat panel's "Shoot me at a random spot" button (or F2 in play) fires a real
ray at the player; the hit zone it strikes picks the body region of the wound (ADR 0011).
`HitRegionTests` (PlayMode) covers this.

The mirror: M in play (or "Look in the mirror" in the cheat panel) switches to a camera in front of the
character and lists every mark with its origin, stage, severity and effects. Click a mark to frame its
body region and highlight its marker. It only reads the simulation. Framing values are on the `Mirror`
object. `MirrorViewTests` (PlayMode) covers it.

That proves persistence through the sim with greybox markers on the mannequin's bones. Drawing the scar
into the character's skin needs a real character model and the M1 decal layer.

## The M2 region (fast loop greybox)

`Assets/Scenes/M2_Region.unity` is a 600 m greybox region laid out after the homestead references: the
homestead clearing (three empty building slots and a stand-in cabin), the creek and its guardrail bridge,
the old highway with the fallen overpass, Laurel Woods turning into the deep hollow to the west, the east
meadow, and Buck Ridge to the north. Each place is an `AreaVolume` with area tags and a place name, and
the HUD at the bottom shows where you are, the time, the day and the pack.

- Walk out of the clearing to get the **Setting out** panel: choose companions and pack from the stores
  (the cheat panel's give-item fills the stores; a new game starts with them empty). "Stay home" puts you
  back inside.
- **C** makes camp: sleep until 6:00, which advances the simulation a day. A game day also passes every
  `minutesPerDay` real minutes (on the `Clock` object, for tuning).
- Walk back into the clearing to come home: the pack is unloaded and the **Home** panel shows what came
  back and any season reports from while you were away.

Rebuild it with **Hearthline → Rebuild M2 region scene** or
`unity command script eval --code "return Hearthline.EditorTools.RegionSceneBuilder.Build();"`.
`TripFlowTests` (PlayMode) covers places, leaving, setting out, staying home, coming home and the clock.
